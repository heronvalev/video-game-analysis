# Video Game Analysis

## Overview

This is a personal project built as a coding challenge and exercise to deepen my skills in Python, Flask, data exploration, and visualization. The application provides a web interface to explore a comprehensive dataset of Steam games, offering insights into game genres, ratings, pricing, and more.

## Features

- Search for Steam games by keyword with pagination.
- View detailed game information including release date, developer, publisher, genres, categories, platforms, and ratings.
- Browse games by genres, categories, platforms, or tags.
- Interactive dashboard displaying various charts and visualizations.
- Responsive and user-friendly design using Bootstrap and Plotly.

## Dataset

This project uses data sourced from Kaggle (https://www.kaggle.com/datasets/nikdavis/steam-store-games?select=steam.csv), which includes detailed game information and metadata.

## Installation

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies (requirements.txt).

## Usage

* Use the search bar on the home page or navbar to find games.
* Click on a game to see detailed information.
* Browse by genre, category, platform, or tag using the links available on the game details page.
* Use the dashboard to explore visual charts about the Steam games dataset.
