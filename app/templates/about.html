About This Project

This is a personal project built as a coding challenge and exercise to deepen my skills in Python, Flask, HTML, CSS data exploration and visualization. It offers a comprehensive dataset of Steam games, providing insights into game genres, ratings, pricing, and more.

The raw data used in this project was sourced from Kaggle's Steam Games Dataset .

The project serves as a practical demonstration of my coding and data analysis skills. Feedback and suggestions are welcome!
